# Little Octopus, Big Day — cutest-picture-01

A big round coral-pink baby octopus in pastel water — huge bright eyes glancing sideways, rosy cheeks, a small smile, one tentacle waving, a tilted golden starfish on its head, with bubbles, light rays and a sandy floor.

`main.py` (Python 3.13, standard library only) draws the picture with a small software renderer and writes `entry.png` (1024x1024 PNG) to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset). Deterministic: the same bytes on every run.
